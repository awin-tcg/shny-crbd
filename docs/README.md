## Updating documentation

Every change to a core document must update that document's revision history in
the same change. Record the commit short hash, date, and a concise description
of the meaningful content change; do not infer reviews or reconstruct versions
that are not supported by repository history. Update this index when a
document's purpose, status, or latest content revision changes.
